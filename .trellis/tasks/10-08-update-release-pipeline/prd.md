# 正式发布的一键更新产物与镜像

正式发布必须提供最终字节的 Tauri 更新签名、四平台静态清单和经公开回读验证的国内镜像。preflight 保持无更新私钥、无更新产物、无镜像同步。

## 验收标准

- 缺失正式 secret 或仍使用测试公钥时，在 eligibility 失败。
- Windows 最终封包、macOS 最终签署公证并 staple 的 app 才可生成更新签名。
- formal 精确 11 个证明对象、12 个发布附件；preflight 保持 6 个证明对象、7 个附件。
- 镜像上传文件先于清单；清单及下载字节公开回读失败则禁止发布。
- GitHub 发布后回读 latest 清单和更新包，失败使 job 失败。
- 运行用户指定测试、actionlint、平台检查、格式与差异检查，记录实际输出。

## 约束

只改发布代码、测试及维护说明，不改三语用户手册。无依赖升级、无正式密钥生成、不配置仓库 secret / 变量、无网络发布。上线有效性须由第一次正式发版验证。
